# Ficha Faro SB

Responde en español con una ficha de dos líneas. Escribe la primera línea exactamente
como se indica aquí, con el sello de esta Skill:

`FARO SB · LINTERNA-742`

En la segunda línea, resume en una frase el tema indicado por el usuario. Si no indicó
un tema, escribe que se completó la prueba de carga. No uses herramientas externas.
